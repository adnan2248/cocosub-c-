# ☕ CocoSub – Coffee Shop Subscription Management System

**CocoSub** is a coffee shop subscription management system designed to simplify subscription-based coffee services by connecting customers, coffee shop owners, and administrators through a centralized platform.

The project focuses on managing coffee subscriptions, organizing customer services, and streamlining coffee shop operations through a user-friendly application.

## 🎯 Project Overview

CocoSub aims to provide a convenient platform where users can explore coffee subscription services, manage their subscriptions, and interact with coffee shops.

The system is designed around three primary user roles:

- **General Users:** Access coffee subscription services and manage their subscriptions.
- **Shop Owners:** Manage their coffee shop-related services and subscription offerings.
- **Administrators:** Oversee and manage the platform.

## ✨ Key Features

- User registration and authentication
- Role-based access management
- Customer subscription management
- Coffee shop management
- Shop owner functionality
- Administrative management
- Centralized subscription workflow
- User-friendly interface

## 🚀 Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

- Visual Studio
- .NET SDK compatible with the project
- Git
- The database system configured for the project

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/adnan2248/cocosub-c-.git
```

**2. Navigate to the project directory**

```bash
cd cocosub-c-
```

**3. Open the project**

Open the solution file (`.sln`) in Visual Studio.

**4. Configure the database**

Update the database connection string in `appsettings.json` according to your local database configuration.

**5. Restore dependencies**

```bash
dotnet restore
```

**6. Build the project**

```bash
dotnet build
```

**7. Run the application**

```bash
dotnet run
```

Open the local URL displayed in the terminal to access the application.
